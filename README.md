# はやおし文庫

身内で遊ぶための、みんはや風の早押しクイズPWAです。スマートフォンのブラウザで動き、ホーム画面に追加するとネイティブアプリに近い感覚で使えます。

## 起動

このフォルダで次を実行します。

```bash
npm start
```

ブラウザで [http://localhost:4173](http://localhost:4173) を開いてください。`file://` で直接開くとPWAやオンライン機能が動かないため、必ずローカルサーバー経由で確認します。

更新後に古い画面が表示される場合は、ブラウザをハードリロードしてください。PWAの更新後は、一度ページを再読み込みすると最新のService Workerへ切り替わります。

## 遊び方

- `世界遺産 → 日本 → 北海道・北東北の縄文遺跡群` のようにカテゴリを選択します。
- 階層の親カテゴリで開始すると、そのカテゴリ以下に属する問題がランダムに出題されます。
- 各ラウンドは「第n問」と表示して約1.2秒待ってから、問題文が約0.115秒ごとに1文字ずつ表示されます。PCではスペースキー、スマートフォンでは「わかった！ 早押し」を押します。
- 解答はひらがなのみ入力できます。
- 問題文を最後まで表示してから8秒以内に正解が出なければ、時間切れとして答えを表示し、3.5秒後に次の問題へ自動的に進みます。
- ひとりプレイでは、そのまま答えを入力して正誤を確認できます。
- オンライン対戦では、1人が「部屋を作る」、もう1人がルームコードで参加し、ホストが開始します。

## 問題の追加

右上の歯車から問題を追加できます。追加した問題は、そのブラウザのLocalStorageに保存されます。複数端末で問題を揃える場合は、JSONを書き出して相手の端末で読み込んでください。

問題データには次の項目があります。

```json
{
  "categoryId": "jomon",
  "prompt": "問題文",
  "answer": "答え（表示用）",
  "answerHiragana": "こたえ（ひらがな）",
  "source": "出典（任意）",
  "explanation": "解説（任意）"
}
```

現在のカテゴリIDは `world-heritage`、`japan`、`jomon` です。

## オンライン対戦について

オンライン対戦はPeerJSの無料シグナリングサーバーとWebRTCのP2P接続を利用しています。問題データとゲーム進行はホスト端末が持ち、参加者はルーム内で同期します。身内用の簡易版なので、公開サービス向けの認証・荒らし対策・対戦履歴保存は入れていません。

本番公開する場合は、Azure Static Web Apps、Cloudflare Pages、GitHub Pagesなどにこのフォルダをそのまま配置できます。HTTPSで配信するとスマートフォンへのホーム画面追加とWebRTCが安定します。
